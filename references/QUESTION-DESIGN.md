# Assessment Question Design Policy

The project should build a very large bank of original, specification-aligned science questions informed by official and commercial assessment corpora without becoming a disguised reproduction of those corpora.

## User-facing categories

Use labels such as:

- Check your understanding
- Retrieval
- Apply it
- Data and evidence
- Investigation
- Exam-style practice
- Challenge

At the end of suitable sections, include **Exam-style practice** containing fresh questions at the standard and style students are likely to encounter in Junior Cycle assessment.

Do not imply that a generated question is an actual SEC/DEB question unless it is reproduced lawfully and deliberately as such.

## The abstraction method

When using an existing assessment question as inspiration, first extract a source-free blueprint such as:

- current learning outcome(s);
- scientific concept;
- action verb(s);
- cognitive demand;
- representation required: prose / table / graph / diagram / calculation / experimental setup;
- type of reasoning required;
- misconception or distractor pattern;
- expected response length;
- difficulty and scaffolding level.

Then create the new item from that blueprint rather than by editing the original wording.

## A new question should normally change several dimensions

As appropriate, create a genuinely new:

- context or phenomenon;
- dataset and numerical values;
- graph/table/diagram;
- experimental setup;
- sequence of subparts;
- wording;
- examples/materials/organisms/substances;
- inference or conclusion required.

Changing only names, numbers or a few words is **not** the project standard.

## Similarity review

Before accepting an item inspired by a specific source question, ask:

1. Could the new question have been written independently from the specification and the assessment blueprint?
2. Does it avoid distinctive source phrasing except unavoidable scientific terminology?
3. Is the structure sufficiently independent rather than a part-for-part rewrite?
4. Are the stimulus, data and required reasoning genuinely new where practical?
5. Is it aligned to the current specification rather than merely inherited from an old paper?

If not, rewrite it more fundamentally.

## Using old Junior Certificate papers

Higher and Ordinary papers from 2009–2018 can provide excellent science-question architecture, but they predate the present common-level specification.

Use them for transferable assessment ideas such as:

- experimental reasoning;
- graph/data interpretation;
- calculations;
- diagrams;
- scientific vocabulary in context;
- application of concepts.

Re-map every resulting question to the **current Junior Cycle Science learning outcomes** before inclusion.

## Using current-era papers

The 2019 onward common-level/current-specification corpus is especially useful for:

- stimulus-rich assessment;
- integrating Nature of Science;
- unfamiliar contexts;
- interpreting evidence;
- evaluating investigations;
- linking science, society and sustainability.

Do not assume that repeated past-paper frequency defines curricular importance. The specification remains authoritative.

## Using commercial papers such as DEB

Commercial papers can be analysed in a private reference workflow to broaden the assessment-pattern pool.

They should not be committed to a public repository without appropriate rights, and they should not be converted into project questions by superficial paraphrase.

The intended workflow is:

**source question → assessment blueprint → source put aside → genuinely new question → similarity review → specification check**

## Provenance

Internal development metadata may record broad provenance such as:

- `spec-only`
- `SEC-pattern`
- `legacy-paper-pattern`
- `commercial-paper-pattern`
- `teacher-authored`
- `AI-generated-reviewed`

This metadata is for quality control. User-facing material should normally present the question simply as project-authored exam-style practice.

## Long-term ambition

The assessment bank should become richer than any individual examination-paper collection.

It can include:

- multiple parallel versions of the same underlying skill;
- randomised numerical data;
- misconception-targeting distractors;
- adaptive hints;
- immediate feedback;
- semantic checking for short responses where reliable;
- cumulative retrieval across strands;
- mixed-strand questions;
- automatically generated practice sets at different challenge levels.

**Learn from the assessment corpus. Do not clone it.**
